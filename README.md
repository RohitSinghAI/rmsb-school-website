# RMSB SCHOOL

### Rashtramata Savitribai Phule Mission School, Bhander

A modern, responsive, and user-friendly school website developed for **Rashtramata Savitribai Phule Mission School, Bhander**. The website provides students, parents, and visitors with easy access to school information, admissions, faculty, events, gallery, FAQs, and contact details.

## 🌐 Live Website

**[Visit RMSB School Website](https://rmsb-mission-school.vercel.app/)**

## ✨ Features

- 🏫 Modern School Website
- 📚 School Information
- 📝 Online Admission Section
- 👨‍🏫 Faculty / Teachers Section
- 🖼️ School Gallery
- 🎉 Events & Activities
- ❓ Frequently Asked Questions
- 📞 Contact Section
- 📱 Fully Responsive Design
- ⚡ Fast and User-Friendly Interface

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** Vercel

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/rmsb-school-website.git
```

### 2. Navigate to Project

```bash
cd rmsb-school-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```
